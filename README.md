# Simple To-Do App

This is a beginner-friendly project to learn Git and GitHub operations using VS Code.

## Features

- Add tasks
- Display task list

## How to Run

1. Open `index.html` in your browser.
2. Add tasks and view them in the list.

## Git Operations to Try

- Clone
- Branching
- Commit / Push
- Pull Request
- Merge Conflicts
- Rebase
- Reset / Revert
